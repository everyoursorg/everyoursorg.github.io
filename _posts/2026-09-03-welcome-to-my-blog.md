# Welcome! 🎉

This is your first blog post! You can edit or delete this file and start writing your own posts.

## How to Create New Posts

1. Create a new file in the `_posts` directory
2. Name it with the format: `YYYY-MM-DD-title.md`
3. Add front matter at the top (the `---` section)
4. Write your content in Markdown
5. Push to GitHub and your site updates automatically!

## Example Post Structure

```markdown
---
layout: post
title: "Your Post Title"
date: 2026-09-03 12:00:00 -0000
categories: category-name
---

Your post content here in Markdown!
```

## Markdown Tips

- **Bold:** `**text**`
- *Italic:* `*text*`
- [Links](https://example.com)
- `Code blocks with backticks`
